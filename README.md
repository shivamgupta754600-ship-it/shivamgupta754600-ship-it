## 💻 Featured Projects

### 🤖 SmartResolve AI

An AI-powered grievance routing system that classifies public complaints and routes them to the appropriate government department.

**Tech:** Python • Scikit-learn • FastAPI • MySQL • React

**Key Features:**

- 🌐 English, Hindi, and Hinglish support
- 🤖 Machine learning based grievance classification
- 🎯 Automatic category routing
- 📊 Confidence-based predictions
- 👤 Human review for uncertain predictions
- ⚡ REST API backend using FastAPI

---

### 📄 RAG PDF Chatbot

A Retrieval-Augmented Generation application that allows users to upload PDF documents and ask questions about their content.

**Tech:** Python • LangChain • ChromaDB • RAG

**Key Features:**

- 📄 PDF document processing
- ✂️ Document chunking
- 🔎 Semantic retrieval
- 🗄️ Vector database using ChromaDB
- 💬 Question answering over documents
